Verified use-case checks
------------------------
- GET /cart without authentication returns 403 as expected.
- POST /cart/items with missing productId or quantity returns 422 as expected.
- POST /payments/intent without authentication returns 403 as expected.
- GET /inventory without authentication still resolves through the handler and returns an access-control response based on role context.

Common error cases
-----------------
- Missing or invalid input returns 400/422 depending on the endpoint.
- Unauthorized requests return 403.
- Missing resources return 404.
- Duplicate or conflicting requests can return 409.
